# RobotWin2 runtime for VFA

This directory contains RobotWin2 task environments, collection/evaluation
scripts, and the RTPolicy adapter used by VFA. Setup and usage are documented in
the [runtime notes](../../docs/README.md).

Objects, textures, embodiments, URDFs, meshes, pretrained weights, collected
datasets, evaluation videos, and cuRobo source are external runtime dependencies.
Download assets with `bash script/_download_assets.sh`; install simulation
dependencies with `bash script/_install.sh` in a compatible NVIDIA environment.
